# Welling Growth Audit

**Live → https://eddieatadapty.github.io/welling-flow-rebuild/**

Five ideas to turn more Welling users into subscribers, each built into a clickable version of Welling's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to purchase |
| 02 | Ask for notifications after the paywall, not on screen one | +10–15% CR to purchase |
| 03 | Put the proof where the decision happens | +10–15% CR to purchase |
| 04 | Let them log a meal before they pay | +5–15% CR to purchase |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Welling's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Welling. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
